                                Финансовый ИИ Ассистент

Telegram Mini App для учёта личных финансов с интеграцией искусственного интеллекта.

Приложение позволяет пользователям записывать доходы и расходы с помощью обычных сообщений на русском языке. ИИ анализирует текст, определяет финансовую операцию и передаёт структурированные данные backend-приложению для сохранения в базе данных.

##  Возможности

-  **ИИ-ассистент** — понимает сообщения на естественном языке.
-  **Учёт доходов и расходов** — распознаёт тип операции, сумму, категорию и дату.
-  **Категоризация операций** — распределяет транзакции по категориям.
-  **Редактирование транзакций** — позволяет исправлять данные существующих операций.
-  **Удаление транзакций** — удаляет выбранные записи по команде пользователя.
-  **Уточнение информации** — запрашивает недостающие данные и поддерживает контекст диалога.
-  **Статистика финансов** — отображает информацию о доходах и расходах за разные периоды.
-  **Интерфейс Telegram Mini App** — удобный доступ к финансовому помощнику внутри Telegram.

##  Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <https://github.com/klkmyf/finance_assistant>
cd <ПАПКА_ПРОЕКТА>
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```


Активация в Windows:

```bash
venv\Scripts\activate
```

Активация в Linux или macOS:

```bash
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env

GROQ_API_KEY=ваш_api_ключ

GROQ_API_KEY =ваш_api_ключ

DB_NAME=...
DB_USER=postgres
DB_PASSWORD=...
DB_HOST=127.0.0.1
DB_PORT=5433
```

### 5. Применение миграций

```bash
python manage.py makemigrations
python manage.py migrate
```

### 6. Запуск сервера

```bash
python manage.py runserver
```
После запуска сервера нужно добавить порт 8000 и сделать его публичным.

### 7. Запуск бота

```bash
python bot.py
```

##  Как работает ИИ

1. Пользователь отправляет сообщение в чат.
2. Django Channels получает его через WebSocket.
3. Модуль `ai.py` отправляет запрос в Groq API.
4. ИИ анализирует сообщение и возвращает структурированный JSON.
5. `consumers.py` обрабатывает действие и выполняет необходимые операции с базой данных.
6. Пользователь получает ответ в чате.

Например, пользователь пишет:

> Сегодня потратила 3000 ₸ на продукты.

ИИ определяет тип операции, сумму, категорию и дату. Backend сохраняет транзакцию в базе данных.

При редактировании и удалении приложение должно проверять принадлежность записи пользователю и не изменять данные, если нужную транзакцию нельзя определить однозначно.

##  Модели данных

В проекте используются следующие модели:

- **UserProfile** — профиль пользователя Telegram.
- **Category** — категории финансовых операций.
- **Transaction** — информация о доходах и расходах, включая сумму, тип, категорию и дату.

##  Безопасность

- API-ключ хранится в переменных окружения.
- Финансовые данные обрабатываются на backend.
- Изменение и удаление транзакций должны выполняться только по команде пользователя.
- При работе с Telegram Mini App необходимо проверять подлинность `initData` на сервере.
- Доступ к транзакциям ограничивается владельцем записи.
